# AI Prompts

I used ChatGPT to help review and simplify my DataMan text-only prototype.

## Prompts Used
- Review my app.py, logic.py, and store.py files for unnecessary code.
- Need assistance with storing up to 10 problems in Memory Bank in random order.
- Does this code support JSON File storage.
- Any improvements or recommendations for my current learner ID placeholder.
## How AI Helped
ChatGPT helped me identify unnecessary code, simplify the project, review the separation between the three layers,
and document the prototype. I reviewed the suggestions and made changes to my code.
